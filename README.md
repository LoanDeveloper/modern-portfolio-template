# Modern Portfolio Template

A modern, responsive portfolio website template for fullstack developers. Built with Next.js 15, TypeScript, and a carefully curated stack of modern UI libraries to create a professional and polished online presence.

Perfect for developers looking to showcase their projects, skills, and experience with smooth animations and a clean, accessible design.

## Features

- Built with [Next.js](https://nextjs.org) and [TypeScript](https://www.typescriptlang.org/)
- Styling with [Tailwind CSS](https://tailwindcss.com/) for rapid UI development
- Accessible components via [Radix UI](https://www.radix-ui.com/)
- Beautiful icons from [Lucide React](https://lucide.dev/)
- Smooth animations powered by [Framer Motion](https://www.framer.com/motion/)
- Code quality maintained with [ESLint](https://eslint.org/)
- Fully responsive and mobile-friendly design
- Optimized fonts with [next/font](https://nextjs.org/docs/app/building-your-application/optimizing/fonts)

## Getting Started

Clone the repository and install dependencies:

```
git clone https://github.com/LoanDeveloper/modern-portfolio-template.git
cd modern-portfolio-template
npm install
```
Run the development server :
```
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser to view your portfolio.

You can start editing the main page by modifying `app/page.tsx` for instant updates.

Fonts are optimized automatically using [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) and [Geist](https://vercel.com/font).
